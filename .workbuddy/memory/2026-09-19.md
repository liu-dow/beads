### 关键约定与踩坑

- **`MOTIFS` 与 `FINE_MOTIFS`**：连续构图（不重复）的 motif 必须加进 `FINE_MOTIFS`，
  否则 `tests/portfolio.test.mjs` 的列周期断言会失败。zellige 是真重复，故意不加。
- **重复周期**：测试里 `repeat = cols%28===0 ? 28 : 24`。136 % 28 = 24，
  所以 136 列的图样若要过周期断言，周期必须是 **24**，不是 28（zellige 因此定 24）。
- **几何约束**：x = col*136/cols，y = (row+(col%2)*.5)*.882*40/rows；
  rows=40 时 y 最大 ≈ 34.84，故图元半径上限约 14（中心 17.4）。
- **落珠尺度经验**：任何特征的厚度必须 ≥2 颗珠，否则边缘会碎成单颗噪点
  （鸢尾花瓣最初 1 珠金边 → 满屏噪点，最后放弃鸢尾改画蕨叶螺旋）。
  螺旋在此尺度最稳；花瓣/花蕊类容易糊成一团。
- **月相公式**：`lit = along >= cos(phi)*sqrt(1-py²)`，waxing 用 px，waning 用 -px；
  照亮区必须**压过金边**，否则娥眉月会被自己的描边吃掉。
- 新增作品后需 `node scripts/generate-pattern-previews.mjs --work=<slug>` 生成
  1200×960 的 .png/.webp 与 -bracelet.webp，测试会校验 PNG 头部尺寸。
- 调色板尾部未使用的颜色可直接删除，但**不能删中间项**（cells 存的是索引）。
